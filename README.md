# Ensayo
![Android CI](https://github.com/Oscar-carpio/ensayo/actions/workflows/android.yml/badge.svg)git add README.md

Offline-first Android app for bands and worship teams: songs with chords, instant transposition, setlists and a live stage mode.

**Stack:** Kotlin · Jetpack Compose · Room · Hilt · Coroutines/Flow · Retrofit · Spring Boot backend

🚧 Work in progress. See the roadmap in GitHub Projects.gi
